# 飞书转公众号排版工具

一个纯静态网页工具，用来把飞书文档复制出来的富文本，转换成微信公众号后台更稳定识别的内联样式 HTML。

## 怎么用

1. 在飞书文档里全选正文并复制。
2. 打开 `index.html`，把内容粘贴到左侧输入区。
3. 检查右侧公众号预览。
4. 点击“复制到公众号”，去公众号后台粘贴。

## 核心逻辑

- 读取飞书复制出来的富文本 HTML。
- 清理飞书专用的隐藏标记和不稳定属性。
- 默认使用“公众号排版”模式，自动优化标题、正文行距、段落间距和重点句。
- 自动识别短标题、编号标题，以及飞书里加粗、标色、高亮的重点内容。
- 也可以切换到“保持原格式”模式，尽量保留安全的字体、字号、颜色、行距、分段、加粗、高亮、引用、列表、表格等内联样式。
- 给公众号需要的段落、标题、列表、图片、表格补齐基础样式。
- 将结果作为 `text/html` 富文本写入剪贴板。

## 本地预览

直接打开 `index.html`，或运行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```
